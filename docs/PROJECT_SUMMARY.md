### i18n Pattern
```typescript
// middleware.ts - Intelligent detection
export function middleware(request: NextRequest) {
  const detectedLocale = 
    detectFromCookie(request) ||
    detectFromAcceptLanguage(request) ||
    detectFromGeo(request) ||
    defaultLocale
  
  // Auto-redirect + set cookie
  response.cookies.set('preferred-locale', detectedLocale, { maxAge: 31536000 })
  return NextResponse.redirect(`/${detectedLocale}${pathname}`)
}
```

## 🎓 Lessons Learned

### 1. Server Components Are Game-Changers
**Learning:** Default to Server Components, only use Client when needed

**Benefits:**
- Faster page loads (less JS shipped)
- Better SEO (content in HTML)
- Easier to maintain
- Natural data fetching pattern

**Pattern Established:**
```typescript
// Server Component (default)
async function Page() {
  const data = await fetchData()
  return <Content data={data} />
}

// Client Component (only for interactivity)
'use client'
function InteractiveFeature() {
  const [state, setState] = useState()
  return <button onClick={...}>...</button>
}
```

### 2. Schema.org Is Essential
**Learning:** Comprehensive schemas = Rich snippets = Higher CTR

**Impact:**
- Organization schema: Knowledge graph
- Product schema: Product carousel
- Article schema: Featured snippets
- FAQPage schema: Voice search results
- Review schema: Star ratings in SERP

**ROI:** 1 day implementation → 20+ rich snippet opportunities

### 3. Function-Based Schemas > Components
**Learning:** Server-side schema generation is cleaner

**Why:**
- No client component needed
- Type-safe with TypeScript
- Easy to test
- Reusable across pages

**Pattern:**
```typescript
// lib/schema.ts
export function generateSchema(data) {
  return { '@context': 'https://schema.org', ... }
}

// Usage in page
const schema = generateSchema(pageData)
<script type="application/ld+json"
  dangerouslySetInnerHTML={{ __html: JSON.stringify(schema) }}
/>
```

### 4. TypeScript Strict Mode Saves Time
**Learning:** Catch errors early, deploy with confidence

**Examples Caught:**
- Optional property access → Use optional chaining
- Window extensions → Check property existence
- Type mismatches → Fix before build
- Missing translations → Compile-time check

**Time Saved:** ~2 hours of production debugging

### 5. Documentation Is Critical
**Learning:** Phase summaries enable continuity

**Benefits:**
- Easy handoff to other developers
- Quick reference for decisions made
- Audit trail for changes
- Onboarding material

**Pattern:**
- Write summary after each phase
- Document issues and solutions
- Include code examples
- Track metrics and impact

### 6. Build Often, Deploy Confidently
**Learning:** Run `npm run build` after major changes

**Caught Issues:**
- TypeScript errors
- Missing dependencies
- Client component violations
- Schema validation errors
- Missing environment variables

**Workflow:**
1. Make changes
2. Test locally (npm run dev)
3. Build (npm run build)
4. Fix issues
5. Commit
6. Deploy
